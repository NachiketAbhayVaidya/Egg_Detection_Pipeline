# Egg Detection and Tracking Project

This project builds a computer-vision pipeline to detect and track eggs in video frames. It combines color-based segmentation, contour filtering, candidate selection, and temporal tracking to follow multiple eggs across a sequence.

## Project goal

The code is designed for a fixed-camera setup where eggs appear as bright white objects on a table, and the pipeline must:

- detect egg-like blobs in each frame
- reject false positives and partial shapes
- assign detections to track IDs over time
- maintain egg tracking even during brief missed detections
- output metrics for evaluation and rendered tracked video output

## Repository layout

- `src/classical.py` – classical image-processing baselines and candidate generation methods
- `src/video_mask.py` – white-mask segmentation and blob/egg filtering logic
- `src/video_track.py` – frame-to-frame tracking and assignment logic
- `src/metrics.py` – IoU, Dice, precision, and recall metrics
- `src/evaluate.py` – evaluation on image splits
- `src/video_render.py` – renders tracked video output
- `src/step1_split.py` – data split generation for development and evaluation sets
- `src/check_masks.py`, `src/check_masks2.py` – inspection helpers for mask validation
- `src/video_step1.py`, `src/video_step2.py`, `src/video_timeline.py` – video processing helpers
- `src/tune.py`, `src/diagnos.py`, `src/diagnose_condidates.py` – tuning and diagnosis utilities

## Data assumptions

The project expects:

- an input video at `input.mp4` in the project root
- image datasets under `data/all_images/`
- ground-truth masks under `data/masks/`
- a split file generated by `src/step1_split.py` at `src/split.json`

## Typical workflow

1. Build the dataset split:

```bash
python src/step1_split.py
```

2. Evaluate a detection method on the development split:

```bash
python src/evaluate.py t12b
```

3. Run the video tracker and render a processed output:

```bash
python src/video_render.py
```

4. Inspect tracker statistics:

```bash
python src/video_track.py
```

## Core detection idea

The detection pipeline uses a LAB-based white-mask threshold that isolates bright egg-like regions. Candidate blobs are then checked for:

- area range
- shape solidity
- aspect ratio
- contour convexity
- center-to-image position heuristics

This reduces the search space before picking the best candidate egg mask.

## Tracking logic

Tracking is implemented in `src/video_track.py` using:

- a Hungarian assignment for associating current detections with previous tracks
- a motion gate based on candidate egg width and missed-frame tolerance
- OpenCV trackers (`CSRT`, `KCF`, `MIL`) as fallback when direct detections are missed
- drift and white-pixel checks to reject bad follow-ups

The tracker keeps a `real` vs `tracked` state for each egg in every frame and emits a reconstructed video showing both types.

## Evaluation metrics

`src/metrics.py` computes:

- IoU
- Dice coefficient
- precision
- recall

These are used to compare predicted masks against ground truth segmentation masks.
